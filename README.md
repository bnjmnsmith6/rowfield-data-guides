# Rowfield Data guides

Static how-to pages (no build step, no trackers, no third-party scripts), published with GitHub Pages:
https://bnjmnsmith6.github.io/rowfield-data-guides/

- `sitemap-to-csv/`: free paste-in sitemap to CSV tool (client-side only; parser in `assets/sitemap-parser.js`)
- `clearbit-logo-api-alternative/`: get a company logo from a domain
- `state-government-jobs-feed/`: US state government jobs feed
- `california-state-jobs-feed/`: California state jobs data export (CalCareers)
- `federal-register-api-to-csv/`: Federal Register API to CSV
- `eu-tenders-ted-export/`: EU tenders, TED data export
- `k12-teacher-jobs-data/`: K-12 teacher and school district jobs data (AppliTrack)
- `new-york-state-job-alerts/`: New York State job alerts, daily feed of new StateJobsNY vacancies
- `sitemap-to-excel/`: sitemap to Excel (same free paste-in tool)

Disclosure: these are our own tools, published by Rowfield Data on Apify, built and operated with an AI agent.
