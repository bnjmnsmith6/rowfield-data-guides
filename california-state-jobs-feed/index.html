California state jobs feed (CalCareers)

California posts its state government jobs on CalCareers. If you want those postings as rows for alerts, a job board, a newsletter or research, here is how to get a feed.

Disclosure: these are our own tools, published by Rowfield Data on Apify, built and operated with an AI agent.

What you get

Our California State Government Jobs Scraper (CalCareers) on Apify reads the public CalCareers job search result pages (calcareers.ca.gov), newest postings first, and returns one row per posting:

  • Working title and classification (class title)
  • Department and location (usually a county)
  • Telework (In Office, Hybrid, Telework) and work type
  • Salary text plus salaryMin and salaryMax, as shown on the posting card
  • Publish date, final filing date (empty when the posting says Until Filled) and a link to the posting

No contact names, e-mail addresses or phone numbers. It does not open individual posting pages, so there is no duties or requirements text; open the link for those.

How to set up a daily feed

  1. Open the actor on Apify.
  2. Add filters if you want: keywords (a word in the working title or classification starts with it, for example analyst), departments (for example Transportation), locations (for example Sacramento), telework, minSalary, postedWithinDays.
  3. Set maxPages: result pages of 100 postings, newest first (1 to 30; 30 covers the full list). Filters are applied after reading, so a low maxPages only sees the newest postings.
  4. Turn on onlyNew and add a daily schedule. Later runs return only postings you have not seen before (the memory is a key-value store named calcareers-jobs-memory in your own Apify account).
  5. Export as CSV, JSON or Excel, or read the dataset through the API.

Example inputs:

{"keywords": ["analyst"], "maxPages": 3}

{"keywords": ["engineer"], "departments": ["Transportation"], "maxPages": 30}

{"locations": ["Sacramento"], "onlyNew": true, "maxPages": 30}

Price

Pay per result: $0.50 per 1,000 job postings ($0.0005 per posting) plus $0.00005 per run start. Platform usage is included. Postings removed by your filters or skipped by onlyNew are not charged.

Limits

  • CalCareers sorts by publish date only, so postings with the same date can swap pages during a run and a small share can be missed. With onlyNew on a daily schedule, a missed posting is usually picked up the next day.
  • The result card shows no salary unit. Amounts are kept exactly as shown, not converted.
  • Reads robots.txt first, one request at a time at least 3 seconds apart. Please run it at most once a day.
  • Not made by or affiliated with the State of California or CalHR.
