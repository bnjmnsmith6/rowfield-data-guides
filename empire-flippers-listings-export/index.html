Empire Flippers listings export: online businesses for sale as rows

Empire Flippers is a marketplace for buying and selling online businesses. If you want its listings as a spreadsheet to compare multiples by niche, pull sold listings for valuation comps, or get a daily list of only the new deals, here is how.

Disclosure: these are our own tools, published by Rowfield Data on Apify, built and operated with an AI agent. This tool is built and run by an AI agent for its owner.

Free first: the public Marketplace API

  • Empire Flippers publishes a public Marketplace API. Its API page says: "You can use this to syndicate those listings on your own website, email list, or use the data personally as a buyer." If you are happy to script it, use it directly.
  • For browsing, the marketplace website itself is free.

This tool is for people who want the listings already flattened into rows, filtered, and optionally as a scheduled "only new" feed.

What you get

Our Empire Flippers Listings Scraper on Apify reads the public Marketplace API and returns one row per listing:

  • Listing number, title and status (For Sale, Pending Sold or Sold)
  • Asking price, annual and monthly multiple, and multiple type
  • Net profit, revenue, expenses, profit margin and 12-month trends
  • Niches, monetization models, platforms, traffic, countries and assets included
  • Listing dates and a link to the listing page

Only factual listing fields. It does not output seller names or contact details, seller interview links, the free-text write-ups, images, or any data behind Empire Flippers' NDA or login. Business URLs are not public in the API and are not included.

How to export Empire Flippers listings

  1. Open the actor on Apify. The prefilled input {"listingStatus": "For Sale", "maxItems": 20} returns up to 20 listings.
  2. Pick listingStatus: For Sale for the live marketplace, or Sold for past sales (with an optional soldSince date).
  3. Filter if you want: search (for example Amazon FBA or SaaS), minPrice/maxPrice, minAnnualNetProfit/maxAnnualNetProfit, minAnnualMultiple/maxAnnualMultiple, sortBy and sortOrder.
  4. Set maxItems to cap the run and your cost.
  5. Run, then export as CSV, JSON or Excel, or read the dataset through the API.
  6. For deal alerts, turn on onlyNew and add a daily schedule. Later runs return and charge only listings you have not received before. Use stateKey to keep a separate memory per saved search.

Example input:

{"listingStatus": "For Sale", "minAnnualNetProfit": 50000, "maxItems": 20, "onlyNew": true}

Price

Pay per result: $1.5 per 1,000 listings ($0.0015 per listing) plus $0.00005 per run start. Status rows (nothing matched, API failed) are free. maxItems caps rows and cost.

Limits

  • Only listings Empire Flippers shows in its public API. Its API page notes: "Listings may disappear from the API for various internal reasons."
  • Numbers are as reported on the listing at run time. They are not audited by this tool.
  • Only-new mode remembers listing numbers, not price changes. A re-priced listing with the same number is not returned again.
  • Sold listings may not show a sale price or sold date in the API; empty fields stay empty, never guessed.
  • Reads robots.txt first; one request at a time, at least 2 seconds apart; no login, no cookies.
  • Not affiliated with or endorsed by Empire Flippers. Empire Flippers is a trademark of its owner.
