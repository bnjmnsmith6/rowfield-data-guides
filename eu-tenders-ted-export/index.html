EU tenders: TED data export

You want new EU public procurement calls for tender from TED (Tenders Electronic Daily) as rows you can filter, share or load into a CRM, with no TED account or API key.

Disclosure: these are our own tools, published by Rowfield Data on Apify, built and operated with an AI agent.

What you get

Our EU TED Tenders Scraper: Calls for Tender on Apify reads the public TED Search API (api.ted.europa.eu) and returns one row per call-for-tender notice, newest first:

  • Notice number (publicationNumber) and notice type
  • Title (in English when TED has an English version, otherwise the original language; titleLanguage says which)
  • Buyer organisation names and buyer countries
  • CPV codes and main CPV, publication date
  • Links to the notice page, XML and PDF, plus a source credit line

Calls for tender only: standard contract notices, social and other specific services notices, and design contest notices. Award notices, prior information notices and corrections are not returned.

How to export tenders

  1. Open the actor on Apify.
  2. Set daysBack (default 3), and optionally countries (ISO alpha-3 codes such as DEU, FRA, POL) and cpvPrefixes (2 to 8 digits, for example 72 for IT services or 45 for construction).
  3. Run, then export as CSV, JSON or Excel, or read the dataset through the API.
  4. For a daily tender feed, turn on onlyNew, set a fixed stateKey and add a schedule. Each run then returns only notices earlier runs did not return.

Example inputs:

{"daysBack": 7, "countries": ["DEU", "FRA"], "cpvPrefixes": ["72"]}

{"daysBack": 2, "cpvPrefixes": ["45"], "onlyNew": true, "stateKey": "construction-daily"}

Price

Pay per result: $1.50 per 1,000 calls for tender ($0.0015 per notice) plus $0.00005 per run start. Status rows (no results, nothing new, service error) are free. maxItems caps rows and cost.

Limits

  • Core search fields only. Deadlines, lot details and full descriptions are in the linked notice XML or PDF.
  • Up to 15,000 notices per run. Use a shorter window or filters for wider searches.
  • No contact fields. Any e-mail or phone text inside a title is removed.
  • Source: TED, Publications Office of the European Union. Notices may be reused under the European Commission reuse policy (Commission Decision 2011/833/EU). Not affiliated with or endorsed by the Publications Office, and it does not use the TED logo.
