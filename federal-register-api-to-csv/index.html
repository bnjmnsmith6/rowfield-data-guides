Federal Register API to CSV

You want new Federal Register rules and notices in a spreadsheet, a database or an AI workflow, one row per document, without writing the API paging yourself.

Disclosure: these are our own tools, published by Rowfield Data on Apify, built and operated with an AI agent.

What you get

Our Federal Register Documents Scraper on Apify reads the public FederalRegister.gov API (no key) and returns one row per document: rules, proposed rules, notices and presidential documents.

  • Document number, type, action, title, abstract and DATES text
  • Publication date, effective date and comment deadline
  • Agencies, FR citation and pages
  • Docket ids, RINs and CFR parts affected, topics, the significant flag
  • Links to the FederalRegister.gov page, the official PDF on govinfo.gov and the Regulations.gov comment page

Metadata only, no full text. Agency contact persons are not collected.

How to get a CSV of new documents

  1. Open the actor on Apify. The prefilled input {"daysBack": 3, "maxItems": 20} returns up to 20 of the newest documents.
  2. Narrow it if you want: documentTypes (RULE, PRORULE, NOTICE, PRESDOCU), agencies (FederalRegister.gov agency slugs such as environmental-protection-agency), keyword, docketId, significantOnly, or a fixed startDate/endDate.
  3. Run, then export the dataset as CSV, JSON or Excel, or read it through the API.
  4. For a daily feed, turn on onlyNew and add a schedule. Later runs return and charge only documents you have not seen before. Use stateKey to keep a separate memory per saved search.

Example input (new EPA rules and proposed rules, daily):

{"daysBack": 1, "documentTypes": ["RULE", "PRORULE"], "agencies": ["environmental-protection-agency"], "onlyNew": true, "maxItems": 100}

Price

Pay per result: $1.50 per 1,000 documents ($0.0015 per document) plus $0.00005 per run start. Status rows (nothing matched, API failed) are free. maxItems caps the run and your cost.

Limits

  • FederalRegister.gov is an unofficial rendition and does not provide legal notice. Each row links the official PDF on govinfo.gov; verify there for legal work.
  • The API pages only the first 2,000 results of a search. Larger windows get a free truncated row; split the dates.
  • Empty abstract, dates, docket or CFR fields are left empty, never guessed.
  • Uses only the API, never the website's HTML pages. Reads robots.txt first, one request at a time, at least 1.5 seconds apart.
  • Not affiliated with or endorsed by the Office of the Federal Register, NARA or GPO.
