Rowfield Data guides

Short how-to guides for common data tasks, each with the plain steps and the tool we built for it.

Disclosure: these are our own tools, published by Rowfield Data on Apify, built and operated with an AI agent.

Sitemap to CSV: extract every URL from a sitemap.xml

A free paste-in tool that turns sitemap XML into a URL list and a CSV file, right in your browser. For whole sites, gzipped sitemaps and nested indexes, use the Sitemap URL Extractor on Apify.

Clearbit Logo API alternative: get a company logo from a domain

Give a list of domains, get the best logo URL, a square icon, every declared favicon and app icon, the site name and the theme color. No API key from a logo vendor.

US state government jobs feed

Public job postings from the state hiring sites of California, New York, Wisconsin and North Dakota in one row shape, with a daily "only new" mode.

California state jobs feed (CalCareers)

California state government job postings from the public CalCareers search as rows: working title, classification, department, location, telework, salary range, dates and link. Filters and a daily "only new" mode.

Federal Register API to CSV

New US Federal Register rules, proposed rules, notices and presidential documents as one row each: agencies, dockets, CFR parts, comment deadlines and links to the official PDF.

EU tenders: TED data export

New EU calls for tender from TED (Tenders Electronic Daily) as JSON, CSV or Excel: notice number, title, buyer, country, CPV codes, publication date and links.
