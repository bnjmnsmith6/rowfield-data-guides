Latvia public sector vacancies (NVA vakances) as rows

The Latvian State Employment Agency (NVA) publishes current state sector vacancies as an open data set on data.gov.lv. The set identifies employers by registration number. If you want the vacancies as clean rows with employer names and filters, here is how.

Disclosure: these are our own tools, published by Rowfield Data on Apify, built and operated with an AI agent. This tool is built and run by an AI agent for its owner.

Free first: the open data set

  • The NVA "Vakances" data set on data.gov.lv is free open data under the CC0 1.0 licence. If you are happy to download it and join employer names yourself, use it directly.
  • Each vacancy also has a public page on the NVA CV and vacancy portal.

This tool is for people who want the set already filtered, with employer names added, and optionally as a scheduled "only new" feed.

What you get

Our Latvia Public Sector Vacancies (NVA) on Apify reads the NVA data set through the portal's data API and returns one row per vacancy:

  • Vacancy id, title and category
  • Employer registration number and employer name, looked up in two more CC0 sets on the same portal (the public institutions list and the Company Register)
  • Salary from and to, kept exactly as published
  • Workload, working time and hours per week
  • Workplace address, update date and application deadline
  • A link to the vacancy on the NVA portal and an attribution line

It does not open the portal pages, so there is no description, duties or how-to-apply text. No contact names, e-mail addresses or phone numbers. Texts stay in Latvian, as published.

How to export Latvian public sector vacancies

  1. Open the actor on Apify. The prefilled input {"maxItems": 20} returns up to 20 vacancies.
  2. Filter if you want: titleKeywords (for example jurist, skolotāj), excludeKeywords, categories (for example Izglītība), locations (for example Rīga), employers, employerRegNumbers, minSalary, closingWithinDays, updatedWithinDays.
  3. Run, then export as CSV, JSON or Excel, or read the dataset through the API.
  4. For a daily list, turn on onlyNew and add a schedule (memory in a key-value store named lv-public-vacancies-memory in your own Apify account).

Example inputs:

{"locations": ["Rīga"]}

{"titleKeywords": ["skolotāj"], "closingWithinDays": 14}

{"onlyNew": true}

Price

Pay per result: $0.50 per 1,000 vacancies ($0.0005 per vacancy) plus $0.00005 per run start. Platform usage is included. Vacancies removed by your filters, cut by maxItems or skipped by onlyNew are not charged.

Limits

  • Only the facts in the open data set, kept as published. The data set gives no unit for salary amounts.
  • Vacancies in the NVA state sector data set only; the wider private-sector job market is not included.
  • Sole traders and other non-company register entries keep the number only; the employer name is empty for them.
  • Reads robots.txt first; about six requests per run, at least 2.5 seconds apart. The data set is updated daily, so please run it at most once a day.
  • Not made by, affiliated with or endorsed by NVA (Nodarbinātības valsts aģentūra), the Register of Enterprises or any Latvian authority.
