Use Rowfield Data tools from an AI agent (MCP server)

You want Claude Desktop, Cursor or another MCP client to call our data tools directly: government jobs, bids and tenders, Federal Register documents, sitemaps, logos, link previews, CVEs and more, without writing API code.

Disclosure: these are our own tools, published by Rowfield Data on Apify, built and operated with an AI agent. The MCP config repo and the MCP Registry listing are ours too. Each tool call starts an Apify Actor run billed by Apify to your own Apify account at that Actor's listed price.

Where it is listed

  • Official MCP Registry: server name io.github.bnjmnsmith6/rowfield-data-mcp, version 0.1.0, remote type streamable HTTP. See the registry entry.
  • GitHub: github.com/bnjmnsmith6/rowfield-data-mcp has the registry file (server.json), ready-made client configs, an install guide for AI coding agents and the full tool table with prices.

How it works

The repo has no server code of its own. The tools run on Apify's hosted MCP server (https://mcp.apify.com), which turns Apify Actors into MCP tools. The tools URL parameter picks which Actors your client sees. Each Actor shows up as a tool named founder-experiment--<actor-name>, for example founder-experiment--sitemap-url-extractor. Apify's server also adds helper tools such as get-dataset-items.

What you need

  • An MCP client that supports remote (streamable HTTP) servers, or Node.js for the local option.
  • An Apify account. Sign in with OAuth when your client asks, or use your own API token from Apify Console, API & Integrations.

How to connect the MCP server

  1. Open your client's MCP config (Claude Desktop: claude_desktop_config.json; Cursor: ~/.cursor/mcp.json or .cursor/mcp.json).
  2. Add one of the configs below. All 20 tools use the same server URL as the registry entry.
  3. Restart or reload the client and list tools. You should see founder-experiment--... tools.
  4. Ask for data, for example "Get every URL from the sitemap of example.com and give me a CSV."

Option 1: OAuth (no token in the file; the client opens an Apify sign-in on first connection):

Price

The MCP config and registry listing are free. You pay only for Actor runs, billed by Apify to your account at each Actor's pay-per-result price plus $0.00005 per run start; for example the sitemap extractor is $0.25 per 1,000 URLs. Prices for every tool are in the repo tool table and on each Store page, which is the source of truth.

Limits

  • You need your own Apify account; runs bill to it.
  • Each tool works the way its Actor does, with the same inputs and limits as described in its guide on this site.
  • The server itself is Apify's. Rowfield Data publishes the Actors and the config, not the MCP server software. Not affiliated with or endorsed by Anthropic, Cursor or the MCP project.
