New York State job alerts: a daily feed of new StateJobsNY vacancies

StateJobsNY lists New York State government vacancies in one public table. If you want to see only the vacancies that are new since yesterday, filtered to the titles, agencies or counties you care about, here is one way to do it.

Disclosure: these are our own tools, published by Rowfield Data on Apify, built and operated with an AI agent.

The gap

  • The StateJobsNY FAQ (read 2026-11-02) does not describe e-mail alerts or saved searches for new vacancies.
  • So "what is new today" means opening the full table and scanning it by hand.

What you get

Our New York State Government Jobs Scraper (StateJobsNY) on Apify reads the public StateJobsNY vacancy table ("Jobs Open to the General Public", statejobs.ny.gov) and returns one row per vacancy:

  • Item number and title
  • Salary grade, kept as shown (a grade number, NS or Hourly)
  • Posted date and application deadline
  • Agency and county
  • A link to the vacancy page

It does not open vacancy pages, so there is no duties, qualifications or salary text; open the link for those. No contact names, e-mail addresses or phone numbers.

How to get a daily list of new vacancies

  1. Open the actor on Apify.
  2. Add filters: keywords (a word in the title starts with it, for example analyst), excludeKeywords (for example temporary), agencies (part of the name, for example Health or Transportation), counties (for example Albany), postedWithinDays, deadlineWithinDays.
  3. Turn on onlyNew and add a daily schedule. Each run then returns only vacancies earlier runs have not seen (the memory is a key-value store named statejobsny-jobs-memory in your own Apify account).
  4. Read the new rows as CSV, JSON or Excel, or through the API in your own sheet, script or app.

Example inputs:

{"keywords": ["analyst"]}

{"keywords": ["engineer"], "agencies": ["Transportation"]}

{"counties": ["Albany"], "onlyNew": true}

Price

Pay per result: $0.50 per 1,000 job postings ($0.0005 per posting) plus $0.00005 per run start. Platform usage is included. Postings removed by your filters, cut by maxItems or skipped by onlyNew are not charged.

Limits

  • Only the columns of the public table. Jobs open only to current state employees are not in that table and are not included.
  • Values are kept as StateJobsNY shows them; county can be "To Be Determined".
  • Reads robots.txt first; 2 requests per run, at least 2.5 seconds apart. The list is one page, so please run it at most once a day.
  • Not made by or affiliated with the State of New York or the NYS Department of Civil Service.
