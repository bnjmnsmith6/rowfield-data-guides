SaaSHub alternatives export: competitor lists as rows

You have a list of software products and want the alternatives SaaSHub ranks for each one, as rows you can sort, compare or load into a sheet, with the license credit already on every row.

Disclosure: these are our own tools, published by Rowfield Data on Apify, built and operated with an AI agent.

The official API first

SaaSHub has its own public API (marked beta on its API page, read 2026-11-02). It needs the API key from your SaaSHub profile, returns the top 10 alternatives for a query as JSON, and asks you to disclose on your website that you use it. If that covers you, use it.

This tool needs no SaaSHub key, takes up to 500 products per run, and returns flat rows with source, license and attribution fields.

What you get

Our SaaSHub Software Alternatives Scraper on Apify reads the public alternatives page of each product you list (for example saashub.com/notion-alternatives) and returns one row per ranked alternative:

  • Your query, the product, its SaaSHub rating, review count and the page's last-update date
  • Rank, alternative name, community votes and the alternative's own SaaSHub link
  • Source URL, license name, license URL and an attribution line on every row

Not collected: product descriptions, taglines, features, prices, user reviews, logos or screenshots. Sponsored and featured cards are skipped, so ranks count organic entries only.

How to export alternatives

  1. Open the actor on Apify and list your products: names, SaaSHub slugs or SaaSHub URLs (for example notion, monday). If a name does not match, copy the slug from the SaaSHub page URL.
  2. Optional: maxAlternativesPerProduct keeps only the top N per product; maxItems caps the run and your cost.
  3. Run, then export as CSV, JSON or Excel, or read the dataset through the API.
  4. To track rankings over time, add a weekly schedule with the same products.

Example input:

{"products": ["notion", "slack"], "maxAlternativesPerProduct": 10, "maxItems": 20}

Price

Pay per result: $1.50 per 1,000 alternatives ($0.0015 per row) plus $0.00005 per run start. Status rows (product not found, blocked, failed) are free.

License and attribution

  • If you share or build on it, keep the attribution and license fields (or an equal credit line with a link) and share your adapted data under the same license.
  • The price pays for the extraction service and adds no extra terms to the data. Product names are trademarks of their owners.

Limits

  • Only the first alternatives page of each product is read: usually the top 10 to 20 alternatives.
  • Rank, votes and ratings are as shown at run time and change over time.
  • Reads robots.txt first; one page per product, at least 2 seconds between requests; no login, no cookies.
  • Not affiliated with or endorsed by SaaSHub.
