Sitemap extractors on Apify compared

You want every URL a website lists in its sitemaps, as a CSV or API rows. Here are the free options and five Apify actors that do it, with prices read from each actor's public Apify Store pricing on 2026-11-02.

Disclosure: these are our own tools, published by Rowfield Data on Apify, built and operated with an AI agent.

One of the five is ours: Sitemap URL Extractor by Rowfield Data, built and operated with an AI agent. We list it with the same facts as the others. Prices change; check each Store page before you rely on them.

Free options first

  • Do it by hand: open https://the-site.com/robots.txt, find the Sitemap: lines (or try /sitemap.xml), and open the sitemap in your browser. Fine for one small site.
  • Our free paste-in tool: Sitemap to CSV turns pasted sitemap XML into a URL list and a CSV download, in your browser. It does not fetch sitemaps or follow indexes for you.
  • No actor fee on Apify: boxbox10/sitemap-extractor has no per-result price on its Store page ("Pay per usage"): you pay only Apify platform usage for the run.

What each one does differently

  • apify/sitemap-extractor (by Apify): extracts URLs from a site's sitemaps and also checks each URL's HTTP status code. Pick it if you need live/dead status for every URL.
  • boxbox10/sitemap-extractor: give it a website; it finds sitemap.xml, robots.txt Sitemap: lines and nested sitemap indexes and returns loc, lastmod, changefreq and priority per URL.
  • logiover/sitemap-to-url-crawler: extracts all URLs from a sitemap.xml recursively, exported as CSV or JSON.
  • onescales/sitemap-url-extractor: give it a sitemap.xml link; it lists every URL in it plus the other sitemap fields.
  • founder-experiment/sitemap-url-extractor (ours): give it domains or sitemap URLs; it reads robots.txt first, follows sitemap indexes up to 5 levels, reads .gz and plain-text sitemaps, returns one de-duplicated row per URL, and has path-regex and lastmodAfter filters. It does not open the listed pages, so no status codes. Domains with no sitemap or a blocking robots.txt get one free status row.

Descriptions above are summarised from each actor's own Store description on 2026-11-02. We did not run the other actors.

How to choose

  • One small site: do it by hand or use the free paste-in tool.
  • You need HTTP status codes: apify/sitemap-extractor.
  • You do not want a per-result fee: boxbox10/sitemap-extractor (you pay platform usage).
  • You want one flat per-URL price with filters and free status rows: our Sitemap URL Extractor.
