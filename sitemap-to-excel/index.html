Sitemap to Excel: convert an XML sitemap to a spreadsheet

Paste the XML of a sitemap (or a sitemap index) below. You get every URL with lastmod, changefreq and priority, and a CSV file that Excel opens directly.

Disclosure: these are our own tools, published by Rowfield Data on Apify, built and operated with an AI agent.

Runs in your browser. This page does not fetch anything and does not upload what you paste.

How to get it into Excel

  1. Open https://the-site.com/robots.txt and look for Sitemap: lines. If there are none, try /sitemap.xml or /sitemap_index.xml.
  2. Open the sitemap URL in your browser, view the source, select all, copy, and paste it above. Or use open a file for a saved .xml file.
  3. Press Get URLs, then Download CSV.
  4. Open the downloaded .csv file in Excel (double-click it, or File, Open). Each column becomes a spreadsheet column: loc, lastmod, changefreq, priority. Save as .xlsx if you want an Excel workbook.
  5. Only need the URLs in one column? Press Copy URLs and paste into cell A1.

If you paste a sitemap index, you get the list of child sitemaps. Open each child sitemap and paste it in turn.

What this free tool does not do

  • It does not download sitemaps for you, follow indexes, or read .gz files. This page makes no network requests on purpose.
  • It writes a CSV file, not an .xlsx file. Excel opens the CSV as a sheet.
