US state government jobs feed

Each state runs its own hiring site with its own layout. If you want state civil service jobs in one list, for alerts, a job board, a newsletter or research, here is one way to get a single feed.

Disclosure: these are our own tools, published by Rowfield Data on Apify, built and operated with an AI agent.

What the feed covers

Our US State Government Jobs Scraper on Apify reads the public job lists of four states and returns one common row shape with a state field:

  • California: CalCareers job search results.
  • New York: StateJobsNY public vacancy table.
  • Wisconsin: Wisc.Jobs public job list.
  • North Dakota: Team ND Careers, Career Openings list.

It reads listing pages only, never job detail pages. It is not made by, affiliated with or endorsed by any of these states.

What you get for each job

State, stable jobId, title, classification, agency, location, posted date, closing date, a link to the posting and the source line. Some fields exist only for some states:

  • California: working title and class title, work type, telework, salary text and min/max (as shown, not converted).
  • New York: salary grade, county as location.
  • Wisconsin: job category, job code title.
  • North Dakota: no posted date on the list.

No description text, contact names, e-mail addresses or phone numbers.

How to get a daily feed of new postings

  1. Open the actor on Apify and pick states with states (CA, NY, WI, ND; default all four).
  2. Add filters if you want: titleKeywords (for example nurse), agencies, locations, closingWithinDays, postedWithinDays.
  3. Turn on onlyNew and add a daily schedule. Later runs return and charge only postings you have not seen before (it remembers up to 80,000 job ids in a key-value store in your own Apify account).
  4. Export as CSV, JSON or Excel, or read the dataset through the API.

Example inputs:

{"titleKeywords": ["nurse"]}

{"states": ["NY", "WI"], "maxItemsPerState": 50, "closingWithinDays": 14}

Price

Pay per result: $1.00 per 1,000 jobs ($0.001 per job) plus $0.00005 per run start. Jobs removed by your filters, cut by your caps or skipped by onlyNew are not charged.

Limits

  • Only the facts on each public list. Agency names, locations and salary units are not standardised across states.
  • California salary text shows no unit; values are not converted.
  • If one state fails (error, robots.txt rule, changed layout), that state is skipped and named in the run status; the others still return.
  • Please run it at most once a day.
