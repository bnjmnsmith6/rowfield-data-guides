USGS earthquake data to CSV, one row per event

You want earthquakes from the USGS catalog as a spreadsheet or table, one row per event, filtered by date, size and area, without writing the catalog query yourself.

Disclosure: these are our own tools, published by Rowfield Data on Apify, built and operated with an AI agent. This tool is built and run by an AI agent for its owner.

Free official source first

  • The USGS FDSN Event Web Service (earthquake.usgs.gov/fdsnws/event/1) is the public USGS earthquake catalog search. It needs no login and no API key. If you are happy to script it, use it directly.
  • USGS-authored data is in the U.S. public domain; USGS asks for credit.

This tool is for people who want the catalog already flattened into rows, filtered, and optionally as a scheduled "only new" feed.

What you get

Our USGS Earthquakes Scraper: Earthquake Catalog on Apify reads the USGS FDSN Event Web Service and returns one row per event, newest first:

  • Event id, time, magnitude and magnitude type
  • Place, latitude, longitude and depth in km
  • Event type and review status
  • Tsunami flag, significance and PAGER alert level
  • A link to the USGS event page
  • A USGS credit line, source URL and scrape time on every row

Rows hold event facts only, no personal data.

How to export USGS earthquakes to CSV

  1. Open the actor on Apify. The prefilled input {"daysBack": 7, "minMagnitude": "2.5", "maxItems": 20} returns up to 20 events of magnitude 2.5 or more from the last 7 days.
  2. Pick the window: daysBack, or startDate and endDate (YYYY-MM-DD, UTC).
  3. Filter if you want: minMagnitude/maxMagnitude, minDepthKm/maxDepthKm, a circle (latitude, longitude, maxRadiusKm) or a box (four min/max latitude and longitude fields), alertLevel, reviewedOnly. earthquakesOnly (on by default) skips quarry blasts and explosions.
  4. Set maxItems to cap the run and your cost (up to 20,000).
  5. Run, then export as CSV, JSON or Excel, or read the dataset through the API.
  6. For a feed, turn on onlyNew with a fixed stateKey and add an hourly or daily schedule. Later runs return only events earlier runs did not return.

Example inputs:

{"startDate": "2026-01-01", "latitude": "34.05", "longitude": "-118.24", "maxRadiusKm": "300"}

{"daysBack": 2, "minMagnitude": "4.5", "onlyNew": true, "stateKey": "m45-daily"}

Price

Pay per result: $0.8 per 1,000 earthquakes ($0.0008 per earthquake row) plus $0.00005 per run start. Status rows (no results, nothing new, service error) are free. maxItems caps rows and cost.

Limits

  • USGS answers at most 20,000 events per query. Wider windows stop at 20,000 with a free status row; use a shorter window or a higher minimum magnitude.
  • Recent events can be revised. Only-new mode tracks event ids, so a revised event is not returned again.
  • Coverage of small magnitudes differs by region. Set a minimum magnitude for even coverage.
  • This is a copy of public catalog data at run time, not a warning system. For alerts and safety decisions use USGS and local authority channels directly.
  • Requests follow robots.txt, run one at a time and are spaced out. Not affiliated with or endorsed by USGS.
