Victoria government jobs data: Careers Vic listings as rows

Careers Vic (careers.vic.gov.au) lists Victorian Government jobs across many organisations. If you want those listings as a spreadsheet or API rows, filtered to the organisations, locations or salaries you care about, here is how.

Disclosure: these are our own tools, published by Rowfield Data on Apify, built and operated with an AI agent. This tool is built and run by an AI agent for its owner.

Free first: the Careers Vic site

  • The Careers Vic job listing (careers.vic.gov.au/jobs) is public and free to search, with no login.
  • If you only want to browse or apply, use the site directly.

This tool is for people who want the listing as data: one row per job, the same columns every time, and optionally a scheduled "only new" feed.

What you get

Our Victoria Government Jobs Scraper (Australia, Careers Vic) on Apify reads the public Careers Vic listing pages (15 jobs per page) and returns one row per job:

  • Job id, title and organisation
  • Work type (for example ongoing or fixed-term, full-time or part-time)
  • Salary as shown, plus min and max numbers (empty for hourly rates)
  • Grade, occupation and location
  • Closing date as shown and as a date
  • A link to the job and a source line

It does not open individual job pages, so there is no description, selection criteria, reference number or posted date; open the link for those. No contact names, e-mail addresses or phone numbers.

How to export Careers Vic jobs

  1. Open the actor on Apify. The prefilled input {"searchText": "analyst", "maxPages": 3} reads up to 3 listing pages (up to 45 jobs).
  2. Use searchText to send search words to Careers Vic, like its search box, so fewer pages are read. Set maxPages (15 jobs per page, maximum 200) for how far to read.
  3. Filter if you want: titleKeywords, excludeKeywords, organisations, locations, workTypes, minSalary (AUD per year; jobs without a listed salary are kept), closingWithinDays.
  4. Set maxItems to cap the run and your cost.
  5. Run, then export as CSV, JSON or Excel, or read the dataset through the API.
  6. For a feed, turn on onlyNew and add a daily schedule. Each run returns only jobs earlier runs did not return (memory in a key-value store named careersvic-jobs-memory in your own Apify account).

Example inputs:

{"searchText": "analyst", "maxPages": 5}

{"maxPages": 200, "locations": ["Melbourne"], "workTypes": ["Ongoing"], "minSalary": 100000}

{"maxPages": 10, "onlyNew": true}

Price

Pay per result: $0.50 per 1,000 jobs ($0.0005 per job) plus $0.00005 per run start. Platform usage is included. Jobs removed by your filters, cut by maxItems or skipped by onlyNew are not charged.

Limits

  • Only the facts shown on the listing cards. Values are kept as Careers Vic shows them; salary, grade and location are empty when the site shows "not specified".
  • Listing order is the site's order; jobs can shift between pages during a long run (duplicates are removed by job id).
  • Reads robots.txt first; listing pages one at a time, at least 2.5 seconds apart. Please run it at most once a day, and use searchText or a small maxPages when you can.
