Wisconsin state jobs feed: wisc.jobs listings as rows

State of Wisconsin agencies list their open jobs on wisc.jobs. If you want that list as a spreadsheet or API rows, or a daily list of only the new postings filtered by agency, location or category, here is how.

Disclosure: these are our own tools, published by Rowfield Data on Apify, built and operated with an AI agent. This tool is built and run by an AI agent for its owner.

Free first: wisc.jobs itself

  • The public job list on wisc.jobs is free to browse, with no login.
  • If you only want to browse or apply, use the site directly.

This tool is for people who want the list as data: one row per posting, the same columns every time, and optionally a scheduled "only new" feed.

What you get

Our Wisconsin State Government Jobs Scraper on Apify reads the public job list on wisc.jobs (one request per run) and returns one row per posting:

  • Title, agency and agency code
  • Job classification code and title, and job category
  • Location
  • Posting date and deadline date (empty when the posting is open until filled)
  • A link to the posting and an attribution line

It does not open posting pages, so there is no description, duties, salary or how-to-apply text; open the link for those. No contact names, e-mail addresses or phone numbers.

How to export Wisconsin state jobs

  1. Open the actor on Apify. The prefilled input returns up to 20 postings (maxItems).
  2. Filter if you want: titleKeywords (title or classification), excludeKeywords, agencies (for example Corrections), locations (for example Madison or Statewide), jobCategories, closingWithinDays, includeNoClosingDate, postedWithinDays.
  3. Run, then export as CSV, JSON or Excel, or read the dataset through the API.
  4. For a daily list, turn on onlyNew and add a schedule. Later runs return only postings earlier runs did not return (memory in a key-value store named wi-state-jobs-memory in your own Apify account).

Example inputs:

{"locations": ["Madison"]}

{"titleKeywords": ["engineer"], "postedWithinDays": 7}

{"onlyNew": true}

Price

Pay per result: $0.50 per 1,000 jobs ($0.0005 per job) plus $0.00005 per run start. Platform usage is included. Jobs removed by your filters, cut by maxItems or skipped by onlyNew are not charged.

Limits

  • Only the facts on the public list. Internal-only postings are not on it.
  • State agency postings on wisc.jobs only; not cities, counties, school districts or the University of Wisconsin system.
  • Reads robots.txt first; 2 requests per run, at least 2.5 seconds apart. Please run it at most once a day.
  • Not made by, affiliated with or endorsed by the State of Wisconsin.
